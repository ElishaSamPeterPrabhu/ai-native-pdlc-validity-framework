# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 0.1.x   | Yes       |

## Reporting a vulnerability

Please report security issues privately by opening a
[GitHub security advisory](https://github.com/ElishaSamPeterPrabhu/ai-native-pdlc-validity-framework/security/advisories/new)
or emailing the maintainers listed in `pyproject.toml`.

Do not file public issues for undisclosed vulnerabilities.

## Scope

This project is a research-preview CLI and documentation package. It reads local
repository files and user-supplied intake JSON. It does not execute agent
automations or send data to third-party services unless you configure that
separately in your environment.
