POST-OPEN PR GATE (Open PR tool does NOT add labels):
1. Read the actual PR file list.
2. Label:
   - qa-skip ONLY if ALL files are .scss, .tailwind.ts, .stories.ts, docs, or .md
   - Otherwise qa-full (architecture.mdc, component TS, tests = qa-full)
3. QA-depth (you MUST mention this; do not leave QA to guess a library tour):
   - none: copy/docs/comments only (no color/token/theme AC)
   - visual-slice: color, token, theme, outline, spacing, "modern only" / "classic must not change"
   - functional: component TS/behavior; no host blast radius in the AC
   - composition: AC can break hosts AND the component has neighbors in the lookup below
   If unsure between visual-slice and composition: use visual-slice and QA-graph: none.
4. QA-graph:
   - visual-slice and none: always none (do not invent sidenav/tree walks)
   - composition: copy ONLY these lookup neighbors if they apply (do not BFS):
     modus-wc-tree-item → modus-wc-tree-view, modus-wc-sidenav
     modus-wc-tree-view → modus-wc-sidenav
     modus-wc-menu-item → modus-wc-menu, modus-wc-sidenav
     modus-wc-button, modus-wc-alert, modus-wc-card, modus-wc-checkbox, modus-wc-select, modus-wc-menu, modus-wc-sidenav → none
5. Comment the Routing block on the PR, then ADD the GitHub label.

Routing block (required format):
Routing: qa-skip | qa-full
QA-depth: none | visual-slice | functional | composition
QA-scope: <one primary component or control>
QA-themes: modern-only | classic-only | both | n/a
QA-assert: <one line>
QA-graph: none | <neighbor1, neighbor2>

Example (tertiary outline / modern vs classic):
Routing: qa-skip
QA-depth: visual-slice
QA-scope: modus-wc-button tertiary outline
QA-themes: both
QA-assert: modern outline uses base-200; classic outline unchanged
QA-graph: none

Example (tree-item can break hosts):
Routing: qa-full
QA-depth: composition
QA-scope: modus-wc-tree-item
QA-themes: n/a
QA-assert: selection/expand still works
QA-graph: modus-wc-tree-view, modus-wc-sidenav

6. If label add fails: comment the error, add needs-human, STOP.
The run is complete only after the Routing comment is on the PR and the routing label is on the PR (or the human was asked to add the label).
